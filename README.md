# The Dolly Hulet Group - static site
Serve: `python3 -m http.server 8765` then open http://localhost:8765/
Brokerage name, logo, address and suite live ONLY in `site-config.json`.
After editing it, regenerate all pages: `python3 _build/build.py`.
Forms, IDX search, home valuation and booking are placeholders; nothing is sent.
